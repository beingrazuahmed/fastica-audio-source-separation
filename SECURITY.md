# Security and responsible disclosure

For accidental inclusion of participant audio, identifying information, insecure file-handling, or other security/privacy vulnerabilities, **do not post sensitive information in a public GitHub issue**.

Please contact **Md. Razu Ahmed** privately at **razuahmed038@gmail.com** with a concise description and reproducible steps that contain no participant recordings. The maintainer can assess the issue and decide on suitable remediation; no response-time service-level agreement is promised.

This repository performs local desktop computation and does not provide an online upload API. If you accidentally commit private audio, stop sharing it, seek guidance from relevant data owners and institution, and treat published Git history and forks as potentially persistent. `.gitignore` does not remove already-public files.
